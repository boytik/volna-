# CLAUDE.md

Рабочие заметки для ИИ-ассистента по проекту «Волна».
Продуктовый контекст и задачи — в `HANDOFF.md`.

## Design System

Always read DESIGN.md before making any visual or UI decisions.
All font choices, colors, spacing, and aesthetic direction are defined there.
Do not deviate without explicit user approval.
In QA mode, flag any code that doesn't match DESIGN.md.

Практически это значит:

- Цвета — только из `AppColors` (`lib/core/theme/colors.dart`).
  `Color(0x...)` в `lib/features/` быть не должно.
- Радиусы — только `AppRadius.none/sm/md` (0 / 4 / 12).
  Числовой литерал в `BorderRadius.circular()` — ошибка.
- Отступы — `AppSpacing`. Левая ось экрана `AppSpacing.axis`.
- Градиентов и теней в приложении нет. Совсем.
- `Colors.white` не используется: есть `AppColors.paperLift`.
- `AppColors.accent` — заливки и линии. Для **текста** только
  `AppColors.accentPress`: терракота на бумаге даёт 3.0:1 и не проходит AA.
- Ничего, что может уменьшиться: ни стриков, ни «N из M», ни счётчиков на
  иконках, ни увядающих состояний. См. раздел «Правила» в DESIGN.md — это
  ограничения продукта, а не вкусовщина.

## Навигация

Пять вкладок — `Главная · Дневник · Практики · Специалист · Настройки`
(`lib/core/widgets/app_bottom_bar.dart`) и одна кнопка в правом верхнем
углу главной, ведущая в `/path`.

- Оболочка — `StatefulShellRoute.indexedStack` в `lib/app/router.dart`.
  **В ветках лежат только корни вкладок.** Всё остальное пушится поверх
  оболочки и бар прячет — это намеренно, а не недоделка.
- **Новый раздел кладётся по смыслу в одну из пяти поверхностей**
  (см. таблицу в DESIGN.md), а не иконкой в шапку и не в настройки.
  Шестая вкладка не добавляется — пять уже на пределе читаемости
  на 320pt.
- **Экран может жить в двух ролях.** `/help` — вкладка (корень, без
  «назад»), `/specialist` — тот же экран, пушенный из глубины (с
  «назад» по `canPop()`). Пушить ветку оболочки нельзя: бар вылезет
  поверх экрана, с которого пришли.
- **Вкладки равны:** ни заливок, ни пилюль, ни выделенных кнопок.
  Активная помечается утолщением линейки бара над ней. Счётчиков и
  точек на вкладках быть не может.
- Бар берёт безопасную зону через `MediaQuery.paddingOf(context).bottom`,
  а не `SafeArea`.
- Старые адреса `/sos`, `/calendar`, `/badges` оставлены редиректами:
  ссылки на них раскиданы по экранам. Удалять их нельзя без прохода
  по всем вызовам.

## Ловушки, на которые уже наступали

- **`Column` в `Padding` сжимается по ширине** до самого широкого ребёнка:
  ограничения нежёсткие, `minWidth = 0`. Если внутри есть фиксированный
  `SizedBox`, вся колонка становится его ширины и прижимается влево —
  экран уезжает вбок. Лечится обёрткой в `Center` или
  `crossAxisAlignment: stretch`. Поймано на экране дыхания: контент
  стоял на 56pt левее центра.
- **`Positioned` без `right`** даёт ребёнку бесконечную ширину, и
  `FractionallySizedBox` внутри падает.

## Приватность

Дневник, чек-ины, опросники и записи «выговориться» хранятся только на
устройстве. Сеть используется в одном разделе — «выговориться», — и там
два разных пути:

1. **Распознавание речи.** Сначала пробуем систему телефона
   (`OnDeviceTranscribeService`, `speech_to_text` с `onDevice: true`).
   Тогда аудио не покидает устройство и файла записи не возникает вовсе.
   Если телефон не умеет — откат в Azure с явным согласием.
2. **Ответ.** Транскрипт уходит в Azure OpenAI за эмпатичным ответом
   всегда, в обоих путях. Человек видит текст и правит его до отправки.

**Доступность спрашивается у платформы ДО записи**, через канал
`io.volna.volna/speech` (`AppDelegate.swift`, `MainActivity.kt`).
Плагин заранее не отвечает — падает уже во время записи. Ответ нужен
раньше: от него зависит текст про приватность на экране, а обещание
нельзя уточнять задним числом.

`LeavesDeviceMark` **никогда не проставляется безусловно** — только когда
на этом телефоне аудио действительно уходит. Захардкоженный
`leavesDevice: true` — ошибка, её ловит тест.

Не добавляй сетевых вызовов в другие разделы без явного согласования.
